# Beekapoo roadmap

- **Randomization templates (implemented):** Build saved module sets with Rack module previews in a dedicated collection editor. Search/filter installed modules, click on either side to toggle membership, and automatically fit the chosen modules. Full browser previews, with no live modules or patching. Sets save globally; each Beek chooses its own set.
- **Editable generation rules:** Let users configure and save the input/output connection rules currently defined in JSON. Support global rules, with possible overrides for individual Beeks.
- **Arrange by module (implemented):** Restore module-based grouping. Choose between grouping just the parameters into a block per module, or grouping each module’s parameters, inputs, and outputs together in one block.
- **Front-panel locks (implemented):** Press **L** to show locked exposed parameters and toggle their locks directly on the panel, without opening the subpatch editor.
- **Saved Beek browser:** Browse and choose saved Beeks when adding a new one. Explore a dedicated browser or integration with Rack’s module browser; retain loading from patch files.
